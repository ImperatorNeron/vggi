# WebGL Project: Advanced Surface Rendering with Lighting

## Quick Review

### Task Overview
In this update, I enhanced the WebGL project with advanced shading techniques and lighting effects. The primary goals included implementing Phong shading, using normals with the Facet Weighted Average method, optimizing geometry rendering with indices, and animating a rotating light source around the model.

### Key Changes

1. Refactored Model.js
2. Added DataStructures
3. Added new methods for calc normals and triangled
4. Improved main.js for rotation of light and granularity
5. Rewrote shaders
